# mwgg_igdb — ao variant (2026.05.21)

Published `ao` variant of the MultiworldGG game index. Force-pushed by
the daily-release workflow in the Index repo and tagged on each push as
`ao-YYYY-MM-DD`.

Install with:

```
pip install git+ssh://git@github.com/MultiworldGG/MultiworldGG-Index@game_index_ao
```

The package exports a `_GameIndexClass` singleton at `mwgg_igdb.GameIndex`.
