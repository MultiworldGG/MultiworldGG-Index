# mwgg_igdb — twelve variant (2026.08.25)

Published `twelve` variant of the MultiworldGG game index. Force-pushed by
the daily-release workflow in the Index repo and tagged on each push as
`twelve-YYYY-MM-DD`.

Install with:

```
pip install git+ssh://git@github.com/MultiworldGG/MultiworldGG-Index@game_index_twelve
```

The package exports a `_GameIndexClass` singleton at `mwgg_igdb.GameIndex`.
